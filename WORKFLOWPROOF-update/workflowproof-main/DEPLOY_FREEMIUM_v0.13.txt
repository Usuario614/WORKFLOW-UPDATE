WORKFLOWPROOF v0.13 - FREEMIUM DEPLOYMENT

1) Upload/replace the project files in the GitHub directory:
   WORKFLOWPROOF-update/workflowproof-main/

2) In Render keep:
   Root Directory: WORKFLOWPROOF-update/workflowproof-main
   Build Command: npm install --workspaces=false && npm run build
   Publish Directory: dist

3) Create a Supabase project.
4) Run supabase/schema.sql in Supabase SQL Editor.
5) Add these Render environment variables:
   VITE_SUPABASE_URL = Supabase Project URL
   VITE_SUPABASE_ANON_KEY = Supabase publishable/anon key
   Do NOT use the service_role key.
6) Save environment variables and redeploy.
7) In Supabase Auth URL Configuration, allow:
   https://workflowproof-up.onrender.com/**
8) Test registration, two scans, zero credits, sign-out/sign-in and report download.

Full setup notes: SUPABASE_SETUP.md
