# WorkflowProof sales operations: assisted-audit pilot

This is an evidence-led pilot offer, not a claim that a new tool has already achieved market fit.

## Initial offer

**WorkflowProof assisted preflight — USD 49 pilot price.** One sanitized workflow export, one written audit, prioritized remediation list, risk-acceptance record and one re-audit of buyer-approved changes delivered within two business days. The buyer keeps control of their n8n instance and credentials.

This price is a test hypothesis, not a permanent list price. Record every objection, time-to-delivery and buyer outcome before changing it.

## Qualification

Good early buyers have a workflow about to be deployed, handed over or debugged after an incident; use n8n; and can provide a sanitized export. Decline work that requires secrets, urgent live intervention, regulatory certification, a promised production outcome or an undefined scope.

## First-contact message

"I offer a local preflight for n8n exports before a release or handoff. It produces a written reliability/security evidence pack, does not need instance access, and does not require you to send credentials. For a pilot, I can review one sanitized workflow and return a prioritized remediation plan plus a re-audit after approved changes. If useful, I can send the exact data-handling and delivery scope first."

## Delivery quality checklist

- Verify the export is sanitized; stop if it contains secrets or real operational identifiers.
- Explain every Critical/High finding with node-level evidence and uncertainty where applicable.
- Never enable retries for a mutating operation without buyer-proven idempotency.
- Keep Guided Fix changes as previews until the buyer explicitly approves them.
- Include unresolved findings, accepted risks and their owner/reason/expiry in the final pack.
- Ask the buyer whether the evidence changed a release decision, and request permission before using an anonymized outcome.

## Evidence required to earn a public 9/10 launch score

Five paid pilots, three repeated-need interviews, one approved anonymized case study, an exact-commit CI build and completed legal/support/payment routes. Until these exist, market readiness is unproven even if the technical candidate is strong.
