# WorkflowProof launch assets

## One-sentence positioning

**Catch costly n8n workflow mistakes before they reach production — locally, with evidence, without uploading your workflow.**

## Assisted-audit offer

### Title

I will audit your n8n workflow for reliability, security and duplicate-action risks

### What the buyer receives

- Review of one exported n8n workflow JSON.
- Prioritized findings covering reliability, retries, webhooks, secrets, data safety and AI-risk signals.
- Clear distinction between safe automated changes, guided proposals and manual decisions.
- A share-safe evidence pack and an actionable remediation plan.

### Boundaries

- This is static workflow review, not penetration testing, legal compliance certification or a guarantee of security.
- The buyer supplies a sanitized workflow export and must not send passwords, API keys, tokens or production credentials.
- Implementation, deployment and access to the buyer’s n8n instance are excluded unless separately scoped.

### Launch price and scope

**$49** for one workflow, report and remediation plan. Delivery target: 48 hours after receiving a valid export. Limit the first five deliveries to this price; then test $79.

## Direct outreach message

> I’m testing a local preflight tool for n8n workflows. It reviews an exported workflow before production and flags reliability, duplicate-event, webhook, secret and AI-risk issues without uploading the JSON. I’m offering a bounded workflow audit for $49: one export, prioritized report and remediation plan. It is not a security certification, but it can catch expensive configuration mistakes before a handoff or launch. Interested in testing it on a non-sensitive workflow?

## Case-study structure

Never invent results. For each real case, show:

1. Workflow context and business impact, anonymized with buyer permission.
2. Finding and evidence shown by WorkflowProof.
3. The buyer-approved remediation.
4. Re-audit result and what remains uncertain.
5. A short buyer quote only if actually supplied and approved.
