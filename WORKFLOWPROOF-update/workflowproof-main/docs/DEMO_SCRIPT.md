# WorkflowProof safe demo script

This is a 90-second product demo. Use only the built-in synthetic workflow or a customer-approved sanitized export. Never record an unreviewed customer workflow.

1. Open WorkflowProof and say: "This runs locally in the browser. It does not log into n8n or upload your workflow."
2. Select **Run a safe demo**. Explain that the data is synthetic and its endpoint is non-routable.
3. Point out the finding evidence and severity. Say: "These are deterministic checks that direct review; they are not a security certification or a guarantee."
4. Open the remediation plan. Contrast an automatic low-risk technical fix with a Guided Fix: "Guided Fix shows a preview and waits for approval. It never invents credentials or business rules."
5. Show the production gate: unresolved blocking findings prevent a production-ready signal; accepted risks still reduce the technical score.
6. Show Compare Version and the share-safe Release Pack. Say: "The safe pack applies automated redaction, but the sender must review it before sharing."
7. Close with the service outcome: "You leave with evidence, ownership for any accepted risk and a clear remediation queue. You still validate real behavior in your own n8n environment."

Do not promise that every failure mode is found, that a score guarantees availability, or that a workflow is safe solely because it passed the scan.
